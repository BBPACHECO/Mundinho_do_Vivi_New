# Mundinho do Vivi — baixar no celular

## [⬇ Baixar o APK atualizado — versão 0.6.2 de teste](https://github.com/BBPACHECO/Mundinho_do_Vivi_New/raw/refs/heads/main/downloads/Mundinho-do-Vivi-0.6.2-teste.apk?download=1)

Este repositório disponibiliza o instalador Android de teste. O aplicativo aparece no celular como **Mundinho do Vivi • Teste**.

1. No celular Android, toque no link **Baixar o APK atualizado** acima e aguarde o download.
2. Abra **Meus Arquivos → Downloads → Mundinho-do-Vivi-0.6.2-teste.apk**.
3. Se o Android pedir, permita a instalação pela fonte usada para abrir esse arquivo e toque em **Instalar**.
4. Toque em **Abrir** ou procure o ícone **Mundinho do Vivi • Teste**.

Não use **Code → Download ZIP** para instalar o app: esse botão baixa os arquivos do repositório, não executa o instalador.

- Simba, o mascote Shih-tzu marrom escuro, com focinho e barriga brancos e plaquinha com seu nome.
- Fundo colorido, saudação “OI VAMOS BRINCAR.” e infinito colorido no canto.

Requer Android 10 ou superior. O APK inclui as arquiteturas arm64-v8a, armeabi-v7a, x86 e x86_64. Vídeos online exigem internet; o YouTube pode mostrar anúncios, links e recomendações e não fornece os filtros do YouTube Kids nesta integração. A pesquisa e a reprodução online ainda precisam de validação em aparelho.

## Importante sobre o aplicativo antigo

Esta edição usa `com.mundodedescobertas.app.debug` e **instala separada de Mundinho do Vivi • Família**. Ela não modifica nem importa automaticamente as criações da edição Família. Para usar as novidades, abra o ícone **Mundinho do Vivi • Teste**.

Não temos a chave original da edição Família neste ambiente. Sem essa chave, este instalador não pode atualizar aquela edição por cima. Não desinstale o aplicativo com suas criações para tentar forçar a troca. Uma edição debug instalada de outra fonte também pode usar uma assinatura incompatível.
